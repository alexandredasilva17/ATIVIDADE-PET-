# PetAmigo — site de demonstração

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `site_petamigo`.
3. Clique duas vezes em `index.html` ou abra-o pelo navegador.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: cores, fontes, layout, cards, Flexbox/Grid e responsividade.
- `script.js`: menu mobile, formulário demonstrativo e consumo da API Dog CEO.

## Ajustes importantes antes de entregar
- Troque o número de exemplo no link `https://wa.me/5500000000000` pelo número correto do WhatsApp.
- Personalize nome, textos, imagens e serviços se necessário.

## Recursos incluídos
- Texto e imagens estilizados.
- Layout responsivo para celular e computador.
- Consumo de API pública: `https://dog.ceo/api/breeds/image/random/6`.
- Cards de serviços.
- Flexbox, CSS Grid e largura máxima do conteúdo.
- Menu responsivo.
- Link para WhatsApp.
- Formulário de contato demonstrativo.
